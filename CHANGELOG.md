# Changelog

All notable changes to MeloPulse are documented in this file.

## [0.2.0] - 2026-08-02

- Added a guided CLI journey for recommendation, playback, local catalogue listing, imports, and explicit sync.
- Added stable plain presentation, `--no-color` and `NO_COLOR` support, plus safe JSON success and error routing.
- Added local catalogue listing and richer MCP tool descriptions, annotations, and structured recovery errors.
- Added width-aware contextual human output and schema-preserving structured MCP input errors.
- Expanded installed-tarball smoke coverage for CLI and MCP public journeys.

## [0.1.0] - 2026-08-02

- Initial local CLI and MCP release.
- Local playlist-link import, tagged recommendation, and URL handoff.
- Explicit MeloLab catalogue synchronization and packed-install verification.
